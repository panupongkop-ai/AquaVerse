# 🐠 AquaVerse

ตู้ปลาจำลองแบบโต้ตอบได้ สร้างด้วย HTML, CSS และ JavaScript

🔗 **ลองเล่นได้ที่:** https://panupongkop-ai.github.io/AquaVerse/

## ฟีเจอร์
- เพิ่ม/ลบปลาได้หลายสายพันธุ์
- ให้อาหาร ปลาจะว่ายมากิน
- ลากของตกแต่งในตู้ได้
- สลับโหมดกลางวัน / พระอาทิตย์ตก / กลางคืน

## เทคโนโลยีที่ใช้
HTML, CSS, JavaScript
